Prompt OS

Seven-layer objective runner. One install. Every IDE and CLI. Checkable artifacts — not model confidence.

Prompt OS is a universal kernel that freezes Need, grounds Context, falsifies Hypotheses, attributes Truth, separates Critique, bounds Retrieval, and loops Autonomy (MAPE-K). “Done” is an exit code, not a vibe.

Install

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/youtextme/prompt-operating-system/main/install.sh | bash
# Windows PowerShell
irm https://raw.githubusercontent.com/youtextme/prompt-operating-system/main/install.ps1 | iex
# Seven-layer demo
pos layers run "Ship a sourced brief on LLM self-correction limits"

Install copies the kernel to ~/.agents/prompt-os/, sets ~/.agents/router/PROMPT-ROUTER.md, migrates legacy Outcome OS, and wires Cursor, opencode, Claude Code, VS Code, OpenClaw, and more.

Seven layers

1 Need — Typed objective (success, kill, boundary, boolean DoD) before generation
2 Context — Authorised tools/paths with timestamps; gateway refuses the rest
3 Hypothesis — Falsifiable phase hypotheses; refutations logged to disk
4 Truth — Numbers/URLs sourced or tagged [unverified]
5 Critique — Writer ≠ grader; exit 0/2; theater fails closed
6 Retrieve — Named gap + source + budget; files before generation
7 Autonomy — MAPE-K loop; failure writes next-action, never silence

Nine tenets

GoSolo — Autonomous routing; optional eBPF interception (Linux)
KeepItWarm — Git spine + audit JSONL lineage
TerminalOutcomes — DAG of falsifiable terminal contracts
WayofWorking — Disprove the brief before product code
BarRaiserBoard — Multi-judge panel with minority veto
FeedbackLoop — ≤3 high-leverage human questions at outcome gates
FormulasAndBooleans — evidence-check.mjs exit codes
Evolve&Improve — Golden failure benchmarks + bounded promotion
NoOneBigShotOutcome — Human-usable slices; program stays active until all proven/killed

Verification hierarchy

L1 Formal → L2 Programmatic → L3 Adversarial → L4 Multi-judge → L5 Single judge → L6 Self-grade FORBIDDEN
