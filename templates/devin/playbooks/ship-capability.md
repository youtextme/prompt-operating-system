# Ship a capability — Prompt OS

1. Classify trivial vs non-trivial.
2. Non-trivial: publish **Outcome Frame** (Job, North Star, Key Results, Workback, agents) before product code.
3. Write capability spec to `docs/capabilities/<slug>.md`.
4. Implement on branch `contract/<slug>`.
5. Run `npm test` — do not finish until green.
6. Independent evaluator grades evidence (Builder ≠ Evaluator).

Every response uses STATUS LAW (cook line + status line + trust). **Never** use Jillu banner.
