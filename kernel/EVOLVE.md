# Evolve protocol

The constitution stays tiny. Learning lives here.

## After every proven or killed outcome

Append one block to `evolve/log.md`:

```
## YYYY-MM-DD <slug>
- Outcome: proven | killed | slipped
- Assumption that died:
- What the eval caught that tests missed:
- Missing skill/tool:
- Keep / drop / promote:
```

## Promotion

A pattern may enter `CONSTITUTION.md` only when:

1. It appeared in ≥3 log entries with the same keep reason
2. CONSTITUTION stays ≤50 lines after the edit
3. It is a law, not a playbook (playbooks become skills)

Queue candidates in `evolve/PROMOTIONS.md`. Do not silently grow AGENTS.md or user rules.

## Heartbeat / session start

- Fold duplicate log lines into PROMOTIONS.md
- If an active contract is older than 7 days with no evidence, ping once
- If a skill is referenced 3× as missing, draft it (OpenClaw skill workshop or Cursor skill) instead of stuffing the constitution
